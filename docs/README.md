# Plataforma Digital para la Gestión Integrada y Sostenible del Turismo en Santa Marta

## 1. Descripción del Proyecto
Proyecto de Experiencia Final de Diseño (Capstone Design) para el programa de Ingeniería de Sistemas de la Universidad del Magdalena. El objetivo es diseñar y prototipar la arquitectura de una plataforma digital que integre la oferta turística de Santa Marta, gestione servicios y disponibilidad, promueva el turismo sostenible y soporte escenarios de alta demanda, aplicando principios formales de Arquitectura de Software.
